# New York State Laws

The text of New York's laws, arranged as the printed laws are (law, article, section), with the full
history of every published change since 22 Sep 2014. One commit per weekly publication.

**Read [NOTICE.md](NOTICE.md) first**: unofficial; statute text is not claimed; the Senate's
political-fundraising condition applies; not legal advice.

*Current through the publication of 3 Jun 2022.*

**How to use it:** open a law below, then an article, then a section. Section text is shown line for line
as the Senate publishes it. Each law's page lists its recent changes; [changes/](changes/) has one digest per
publication date. A section's History view (or `git log --follow -- <file>`) is its amendment history.
[How this repository is arranged and built, and how to report an error](#about-this-repository).

## About this repository

### How it is arranged

- **Top-level folders** group the laws by kind: `consolidated-laws`, `unconsolidated-laws`, `court-acts`,
  `legislative-rules` and `constitution`.
- **One folder per law**, named with the law's name as the Senate gives it.
- **Inside a law**, folders follow the law's own divisions (articles, titles, parts), and **each section is one
  file**, named with its number and a shortened form of its heading. For example:
  `consolidated-laws/limited-liability-company-law/article-05-contributions-and-distributions/508-limitations-on-distributions.md`.
- **Numbers are padded with zeros** within a folder so they list in order, and a letter suffix is joined to its
  number (§ 10-a is `10a`), so that § 10 lists before § 10-a.
- **Every folder has a `README.md` page** that lists what is in it. A law's page also shows its recent changes.
- **`chapter-text.md`** in a law's folder holds any text the Senate publishes for the law as a whole, usually
  its table of articles.
- **`changes/`** has one digest for each publication date, listing the sections amended, added, marked repealed
  or removed.
- **`.layout.json`** is a build record (which capture this copy was built from, and how numbers are padded). It
  is not law.

### What a commit is

- **One commit for each date on which the Senate published a change**, in date order.
- **A commit's date is the publication date.** It is not the date a change was enacted, and not the date it
  took legal effect.
- **The first commit (22 Sep 2014) is the starting point**: the text as the Senate published it then. It does
  not mean those laws date from that day.
- **A section's history** lists every publication in which its file changed. A section whose text has not
  changed since the starting point shows only the first commit.
- **Repealed and removed sections.** A section the Senate still publishes but marks as repealed stays as a
  file, marked *Repealed* at the top. A section the Senate stops publishing is deleted in that commit; its
  text remains in the earlier commits.
- **Commit messages** end with `Published-Date`, and with `Source-Repo` and `Source-Commits`, which identify the
  matching entries in the private capture this copy is built from.

### Where the text comes from and how this is built

- **Source.** The New York State Senate's Open Legislation service (legislation.nysenate.gov). See
  [NOTICE.md](NOTICE.md) for the terms that come with it.
- **Capture.** Each published version of each law is captured and stored unchanged.
- **Arrangement.** A program turns that capture into the folders and pages here. Nothing is edited by hand.
- **Check.** Before an update is released, the text on every page is compared with the capture. If anything
  differs, the update is discarded.
- **Currency.** The Senate publishes changes weekly. This copy is refreshed from time to time and can trail
  the Senate; the *Current through* line at the top of this page says how current it is.

### Reporting an error

Open an issue at https://github.com/Bespoke-Legal-Intelligence/New-York-State-Laws/issues and include:

- the law and section;
- the page here (or the commit) where you saw it;
- what the Senate's own site shows.

If the text here differs from what the Senate published, that is an error in this repository and will be
corrected. If the Senate's published text is itself wrong, it is shown here as published.
