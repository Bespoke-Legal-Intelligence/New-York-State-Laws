# Judiciary Law § 296 — Stenographer must file notes with clerk when so directed by court

[Judiciary Law](../README.md) › [Article 9 — Stenographers](README.md)

```text
  § 296. Stenographer must file notes with clerk when so directed by
court. Where the court, or a judge thereof, has made an order, pursuant
to section thirteen of this chapter, directing the stenographer to file
with the clerk, forthwith or within a specified time, the original
stenographic notes taken upon a trial or hearing, the stenographer must
file the same accordingly.
```
