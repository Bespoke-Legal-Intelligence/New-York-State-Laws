# Uniform Commercial Code § 9-606 — Time of Default for Agricultural Lien

[Uniform Commercial Code](../../../README.md) › [Article 9 — Secured Transactions](../../README.md) › [Part 6 — Default](../README.md) › [Subpart 1 — Default and Enforcement of Security Interest](README.md)

```text
Section 9--606. Time of Default for Agricultural Lien.
  For purposes of this part, a default occurs in connection with an
agricultural lien at the time the secured party becomes entitled to
enforce the lien in accordance with the statute under which it was
created.
```
