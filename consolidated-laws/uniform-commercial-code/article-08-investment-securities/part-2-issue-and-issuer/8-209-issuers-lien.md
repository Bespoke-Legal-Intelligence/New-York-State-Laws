# Uniform Commercial Code § 8-209 — Issuer's Lien

[Uniform Commercial Code](../../README.md) › [Article 8 — Investment Securities](../README.md) › [Part 2 — Issue and Issuer](README.md)

```text
Section 8--209. Issuer's Lien.
  A lien in favor of an issuer upon a certificated security is valid
against a purchaser only if the right of the issuer to the lien is noted
conspicuously on the security certificate or, in a case of a cooperative
interest, is set forth in the cooperative record.
```
