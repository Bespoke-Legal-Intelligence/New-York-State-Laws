# Highway Law § 344-P*11 — Portion of the state highway system to be designated as the "Private First Class Richard Cleveland Dunn Memorial Highway"

[Highway Law](../README.md) › [Article 12 — State Routes](README.md)

*An asterisk in a number (for example Article 24\* or § 20-C\*2) is the Senate's mark for a number the Legislature has used more than once: the marked article or section is a different one from the unmarked one with the same number. \*2 means the second one enacted with that number.*

```text
  * § 344-p. Portion of the state highway system to be designated as the
"Private First Class Richard Cleveland Dunn Memorial Highway". All that
portion of the state highway system constituting state route 17M in the
town of Wallkill shall be designated and known as the "Private First
Class Richard Cleveland Dunn Memorial Highway".
  * NB There are 14 § 344-p's
```
